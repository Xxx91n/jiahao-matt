# jiahao-matt

A small script that adds my own rules to an installed copy of `mattpocock/skills`. It reports every place it will change before writing, keeps line endings as they are, and produces one copy of each rule no matter how often it runs.

## Agent skills

### Issue tracker

Issues and specs live as GitHub issues in `Xxx91n/jiahao-matt`. See `docs/agents/issue-tracker.md`.

### Triage labels

The five triage roles use their default label strings. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
