**Write the way the user talks.** Word every question, every recommended
answer, and the reasoning you show in the user's own language: ordinary words,
short sentences, natural spoken flow.

- Name the thing instead of naming a made-up concept. "The strongest
  constraint" says more than a coined label.
- No translationese: do not stack nouns, do not write like a translated
  manual, and never use a word the user has to stop and decode.
- In Chinese, use everyday spoken Chinese, not a word-for-word rendering of
  an English term.
- A recommendation the user has to re-read has failed; rewrite it before
  sending.
